# DropNote

**DropNote** is a local sharing board hosted on an Android phone. Users connected to the same network can share notes, files, and reactions through a web browser.

## Features
- Post notes with names and colors
- Share photos and files (up to 10 MB)
- Like notes
- Search and filter notes
- View connected guests
- Share the board through a QR code
- Manage the board from the Android host app

## Installation

1. Go to the [Releases](../../releases) page.
2. Download the latest `DropNote.apk`.
3. Open the APK on your Android phone.
4. If prompted, allow installation from the source you're using.
5. Install and open DropNote.

## How to Use

1. Open DropNote on the phone that will host the board.
2. Start the server.
3. Share the displayed QR code or server address with other users.
4. Ensure guest devices are connected to a network that allows them to access the host phone.
5. Open the shared address in a browser.
6. Start posting and sharing!

## Requirements
- Android phone for hosting.
- Wi-Fi or a compatible local network for connecting guests.
- Web browser on guest devices.

## Notes
- DropNote is designed for local sharing, not public internet hosting.
- The host phone must keep the server running for guests to access the board.
- Uploaded files are limited to 10 MB.
